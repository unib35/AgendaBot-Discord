# AgendaBot 운영 가이드

AgendaBot을 효과적으로 사용하기 위한 상세 가이드입니다.

## 빠른 시작 (3단계)

### 1. 봇 초기 설정
```
/setup tracking_channel:#안건채널
```

### 2. AI 설정 (선택)
```
/setupkey → API 키 입력
/setup summary_day:월요일 summary_time:09:00
```

### 3. 첫 안건 등록
```
/add → 담당자 선택 → 정보 입력
```

### 4. 리마인더 설정 (선택)
```
/reminder → 대시보드에서 리마인더 관리
```

## 안건 관리 플로우

### 전체 라이프사이클

```
등록(/add) → 토론(스레드) → 진행(/status) → 완료(/done)
```

### 1. 안건 등록

#### `/add` - 새 안건 등록
1. 명령어 입력: `/add`
2. **담당자 선택**: 드롭다운에서 담당자 선택 (선택사항)
3. **정보 입력 모달**:
   - **제목**: 안건 제목 (필수)
   - **배경**: 안건 배경 설명
   - **목표**: 달성하려는 목표
   - **마감일**: YYYY-MM-DD 형식
   - **체크리스트**: 체크리스트 항목 (선택사항)
4. **자동 생성**:
   - 안건 카드 생성
   - 스레드 자동 생성
   - 담당자 멘션 (실제 알림)
   - 진행률 표시 (체크리스트가 있는 경우)

**팁**: 담당자를 선택하면 실제 Discord 알림이 전송됩니다!

### 2. 안건 진행 관리

#### 상태 변경
```
/status id:1 status:검토중
```

**상태 옵션**:
- **진행중**: 작업 진행 중
- **완료**: 작업 완료
- **보류**: 일시 중단
- **취소**: 작업 취소
- **검토중**: 검토 필요
- **대기중**: 대기 상태

#### 체크리스트 관리
```
# 항목 추가
/addcheck id:1 item:디자인 검토

# 개별 체크
/check id:1 item:2

# 일괄 처리
/checkall id:1 action:모두 완료
```

**진행률 자동 계산**: `[2/4] 50% ━━━━━━━━━━`

### 3. 안건 완료

#### `/done` - 안건 완료 처리
```
/done id:1
```

**자동 처리**:
- 상태를 "완료"로 변경
- 모든 체크박스 완료 처리
- 스레드 제목에 [완료] 표시
- 진행률 100%

### 4. 회의록 연결
```
/link id:1 url:https://docs.google.com/...
```

## 리마인더 기능

### `/reminder` - 리마인더 대시보드

리마인더 대시보드로 예정된 회의와 리마인더를 한눈에 관리할 수 있습니다.

**대시보드 기능**:
- **예정된 회의**: 오늘/내일/주간 회의 확인
- **리마인더 목록**: 발송 예정/완료된 리마인더
- **빠른 설정**: 기본 리마인더 정책 설정
- **새로고침**: 실시간 업데이트

### 리마인더 종류

1. **7일 전 알림**: 회의 일주일 전 미리 알림
2. **1일 전 알림**: 회의 하루 전 알림
3. **당일 알림**: 회의 당일 아침 알림
4. **30분 전 알림**: 회의 30분 전 최종 알림

### 반복 안건 설정

안건 등록 시 반복 주기를 설정할 수 있습니다:
- **매일**: 매일 반복되는 안건
- **매주**: 특정 요일마다 반복
- **격주**: 2주마다 반복
- **매월**: 매월 특정 날짜에 반복

## AI 요약 기능

### 초기 설정 (관리자 전용)

#### 1. API 키 설정
```
/setupkey
```
- 모달창에 Gemini API 키 입력
- 키는 암호화되어 저장됨
- Discord 채팅에 기록 안 남음

#### 2. 자동 요약 스케줄
```
/setup weekly_enabled:true summary_day:월요일 summary_time:09:00
```

### 수동 요약 생성

#### `/summary` - 즉시 요약
```
/summary range:이번주 preview:true
```

**옵션**:
- `range`: 이번주/지난주/이번달/지난달
- `preview`: true(미리보기)/false(채널 게시)

#### `/testsummary` - 설정 테스트
```
/testsummary post:false
```

### 자동 요약

설정한 시간에 자동으로 주간 요약 생성:
- 지난 주 안건 분석
- 주요 활동 요약
- 진행 상황 정리
- 다음 단계 제안

## 조회 및 검색

### 안건 목록 조회
```
# 전체 조회
/list

# 상태별 필터
/list status:진행중

# 담당자별 필터
/list owner:@홍길동

# 복합 필터
/list status:진행중 owner:@홍길동
```

### 키워드 검색
```
/search keyword:로그인
```

### 통계 조회
```
# 기간 지정
/stats from:2024-01-01 to:2024-01-31

# 기본 (최근 7일)
/stats
```

**표시 정보**:
- 신규 등록 건수
- 기간 내 완료 건수
- 상태별 현황
- 완료율

## 서버 설정 관리

### `/setup` 명령어 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `tracking_channel` | 안건 출력 채널 | `#안건보드` |
| `command_channel` | 명령어 제한 채널 | `#봇명령어` |
| `allowed_role` | 사용 권한 역할 | `@운영진` |
| `summary_channel` | AI 요약 출력 채널 | `#주간요약` |
| `weekly_enabled` | 자동 요약 활성화 | `true/false` |
| `summary_day` | 요약 실행 요일 | `월요일` |
| `summary_time` | 요약 실행 시간 | `09:00` |
| `week_start` | 주 시작 기준 | `월요일/일요일` |
| `model` | AI 모델 선택 | `gemini-2.0-flash-exp` |
| `show_current` | 현재 설정 확인 | `true` |

### 설정 예시

#### 기본 설정
```
/setup tracking_channel:#안건 command_channel:#봇명령
```

#### AI 요약 설정
```
/setup summary_channel:#요약 weekly_enabled:true
/setup summary_day:금요일 summary_time:18:00
```

#### 권한 제한
```
/setup allowed_role:@멤버
```

#### 현재 설정 확인
```
/setup show_current:true
```

## 채널 운영 규칙 (권장)

### 안건 채널 (#안건보드)
```
안건 채널 규칙
1. 안건 카드에 직접 댓글 금지 (스레드 사용)
2. 스레드에서 상세 논의 진행
3. 완료된 안건 스레드는 보관
4. 주 1회 정리 (선택)
```

### 명령어 채널 (#봇명령어)
```
명령어 채널 규칙
1. 봇 명령어 전용 채널
2. 일반 대화 금지
3. 명령 결과는 개인 메시지로 전송됨
```

## 사용 시나리오

### 시나리오 1: 주간 회의 운영

**월요일 오전**
1. 자동 주간 요약 확인
2. 새 안건 등록: `/add`
3. 우선순위 논의 (스레드)

**주중**
1. 진행 상황 업데이트: `/status`
2. 체크리스트 관리: `/check`
3. 필요시 상태 변경

**금요일**
1. 완료 안건 정리: `/done`
2. 다음 주 계획: `/add`
3. 통계 확인: `/stats`

### 시나리오 2: 프로젝트 관리

**프로젝트 시작**
1. 전체 태스크 등록: `/add` × N
2. 담당자 지정
3. 마감일 설정

**진행 중**
1. 일일 체크: `/list status:진행중`
2. 완료 항목: `/done`
3. 블로커 표시: `/status id:X status:보류`

**프로젝트 종료**
1. 전체 통계: `/stats`
2. AI 요약: `/summary range:이번달`

## FAQ

### Q: 안건 번호를 재사용할 수 있나요?
A: 아니요. 삭제된 안건 번호도 재사용되지 않습니다.

### Q: 여러 명을 담당자로 지정할 수 있나요?
A: 네 가능합니다.

### Q: API 키는 안전한가요?
A: 네. AES-256-GCM으로 암호화되어 저장됩니다.

### Q: 자동 요약이 실행되지 않아요.
A: `/setup show_current:true`로 설정을 확인하고, API 키가 설정되었는지 확인하세요.

### Q: 체크박스가 인식되지 않아요.
A: `⬜` 이모지를 사용해야 합니다. 다른 체크박스 이모지는 인식 안 됩니다.

## 문제 해결

### 봇이 응답하지 않음
1. `/ping`으로 봇 상태 확인
2. 봇 권한 확인 (메시지 전송, 스레드 생성)
3. 명령어 채널 설정 확인

### 안건이 표시되지 않음
1. 출력 채널 설정 확인: `/setup show_current:true`
2. 봇이 해당 채널에 접근 가능한지 확인

### AI 요약 실패
1. API 키 재설정: `/setupkey`
2. 테스트: `/testsummary`
3. 모델 변경: `/setup model:gemini-2.0-flash-exp`
